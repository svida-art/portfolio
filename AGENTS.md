# Project instructions

- Use plain HTML5, CSS and vanilla JavaScript.
- Do not introduce frameworks, static site generators, npm dependencies or build processes.
- Maintain compatibility with GitHub Pages, including repository subpaths.
- Follow DESIGN.md as the primary project specification.
- Support English and German throughout the website.
- Use Sveltia CMS with personal access token authentication.
- Preserve manually defined artwork ordering and original image proportions.
- Keep all editable content separate from presentation code.
- Host public-facing assets locally wherever possible.
- Prioritize simplicity, readability, performance and maintainability.
- Avoid unnecessary abstractions and dependencies.
- Test desktop and mobile layouts after significant changes.
- Do not commit authentication tokens or other secrets.
- Document significant architectural changes.
